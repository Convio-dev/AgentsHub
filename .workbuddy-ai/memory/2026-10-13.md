## Project review — Agents Hub / HermesHub

Analyzed the full codebase (~21.6k LOC, .NET 10 WinForms + WebView2, single-file portable exe).

### Architecture map
`Program.cs` (single-instance mutex + show-window event) → `MainForm` (WebView2 host + tray icon, no WinForms controls) → `ui/index.html` dashboard (9 tabs) ↔ `DashboardWebBridge` (~60 JSON actions in, ~20 push events out, postMessage RPC) → services → external CLI processes.

Services: `CliManagerService` (ConPTY sessions, ports 9119/9229/9339), `HermesProcessService`, `LanProxyService` (0.0.0.0:9191 → 127.0.0.1:9119 TCP proxy), `OpenCodeWatcherService` (sidecar + SSE), `ClaudeOpenRouterProxyService` (Anthropic→OpenAI translation on 127.0.0.1:9230), `AntigravityProfileService` (multi-account via Win32 Credential Manager), `AiConfigService` (%AppData%\AgentsHub\ai_config.json), `PromptEnhancerService`, `ProtonVpnService`, `CliWebTerminalServer`.
Helpers: `NetworkHelper`, `StartupHelper` (HKCU\Software\AgentsHub), `ThemeManager`, `QrCodeHelper`, `ShellLauncher`.
External: hermes dashboard, claude, agy, OpenCode sidecar, OpenRouter, LAN devices.

### Verified findings
- `build-installer.cmd` invokes `ISCC.exe HermesHub.iss` but only `AgentsHub.iss` exists → installer build is broken.
- `Helpers/FirewallHelper.cs` has 0 external references (dead), yet README still advertises the firewall feature.
- `PromptEnhancerForm.cs` never instantiated; `SettingsForm.cs` only reachable from it → both dead code. Dashboard + bridge replaced them.
- `assets/web/*` is a stale near-duplicate of `ui/*`; only `ui/` is loaded (assets/web used only as a fallback for `hermes-offline.html`). `HermesHub.csproj` copies both.
- `ui/tabs/*.html` and `ui/modals/add-profile.html` are never referenced (dead leftovers from a split-file design).
- README is stale: claims v1.0.2, lists only 2 services, wrong project structure. Actual version 1.0.3.
- Version string "1.0.3" hardcoded in ≥6 places (bridge, index.html, dashboard.js ×2, logs.html, assets copies).
- 101 silent `catch {}` blocks across .cs files.
- `Controls/` folder is empty; `Profiles/` empty at rest.
